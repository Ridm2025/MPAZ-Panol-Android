
# MPAZ Pañol

## Descripción
MPAZ Pañol es una aplicación móvil para gestionar el inventario, las reservas y los préstamos de recursos tecnológicos de una institución educativa.

El proyecto se desarrolla como parte de la asignatura Desarrollo de Aplicaciones Móviles (DSY1105).

## Objetivo
Facilitar la solicitud, administración, entrega y devolución de equipos tecnológicos mediante una aplicación Android.

## Tecnologías previstas
- Kotlin
- Jetpack Compose
- Material Design 3
- Arquitectura MVVM
- Room / SQLite
- Navigation Compose
- Git y GitHub
- Trello

## Roles
**Administrador:** gestiona inventario, revisa solicitudes y registra entregas y devoluciones.

**Solicitante:** consulta equipos disponibles, crea reservas y revisa sus solicitudes.

## Funcionalidades planificadas
- Registro e inicio de sesión
- Navegación según el rol
- Catálogo de equipos tecnológicos
- Gestión de inventario
- Carrito de recursos
- Solicitudes de reserva
- Aprobación y rechazo de solicitudes
- Registro de entrega y devolución
- Persistencia de datos
- Validaciones y recursos nativos

## Estado actual
Proyecto Android inicial creado y ejecutado correctamente en un dispositivo físico.

Las funcionalidades del sistema se encuentran en desarrollo.

## Ejecución
1. Clonar el repositorio.
2. Abrir el proyecto con Android Studio.
3. Sincronizar Gradle.
4. Conectar un dispositivo Android o iniciar un emulador.
5. Ejecutar la aplicación.

## Gestión del proyecto
El desarrollo se organiza mediante GitHub y Trello, utilizando épicas y tareas para registrar los avances.
